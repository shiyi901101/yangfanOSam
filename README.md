# 扬帆计划 · 运营中枢（扬帆 OS）

同路生物扬帆计划项目负责人的一站式工作台。前端为**单文件应用**，**没有任何外部 CDN 外链**（PPT / Excel 等组件库随项目同源部署）；数据侧已接入腾讯云开发（CloudBase）云函数，用于论坛跨站互通、看板月度数据上报与智子问答。可直接托管到 GitHub Pages 获得永久链接。

## 这个平台里有什么

- **① 学习**：PMP 教科书级项目管理学习系统（超详细 v5，含敏捷管理、国内外经典案例）。
- **② 提效**：8 个效率工具（成长报告生成、汇报 PPT、执行表、在线收集表、接龙、通知书/证书、短信话术等），支持搜索过滤，常用工具已钉到最前。
- **③ 解惑**：训战机器人，结合扬帆策略 + 真实数据 + 工具包，带新人快速上手、常见问题自查、直接出方案材料。
- **④ 看板**：全站数据驾驶舱，月份动态切换、指标排名、需要盯的站；支持各站自主上传月度数据。
- **⑤ 交流**：项目负责人论坛，按运营进程分板块，热门帖子轮播、发帖回帖可插图、支持搜索排序筛选。

## 部署到 GitHub Pages（拿永久链接）

> 一次配置，链接永不变，浆站人每次打开都带本机记忆。

1. 在 GitHub 新建一个**空仓库**（仓库名随意，例如 `yangfan-os`）。
2. 进入本目录，初始化并推上去：
   ```bash
   git init
   git add -A
   git commit -m "扬帆OS 首版"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

3. 仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录选 `/（root）` → Save。
4. 等 1 分钟左右，访问：`https://<你的用户名>.github.io/<仓库名>/`  
   入口页会自动跳进主平台。

之后要更新内容：改完源文件 → 把新文件拷回本目录 → `git add -A && git commit -m "更新说明" && git push` 即可。

## 几个使用上的实话

- **登录账号**：由管理员在管理端创建（站点账号必须绑定所属站点），密码首次登录后请自行修改。登录态存在浏览器本机（localStorage，同域共享）。权限判定**不在前端**——写权限的归属校验全部落在云函数侧：站点账号只能读写本站数据，论坛内容仅创建者 / 同机构可改，热门 / 置顶仅管理员。
- **数据已云端同步**：论坛帖子、看板月度数据、智子对话、**学员台账**均通过 CloudBase 云函数云端存储，同一账号换设备登录即可看到；本机 localStorage 仅作离线兜底与登录态。学员台账按「一站一桶」物理隔离（`yf-data/students/{slug}.json`），跨站不可见。仍建议用主平台工具栏的「📦 全平台备份」定期导出 json 备档。
- **多站互通**：已实现。全集团浆站在同一论坛互相发帖、共享看板数据，由 CloudBase 云函数 + 云数据库承载（CAS 写入 + 并发锁 + 软删墓碑 + 增量拉取）。
- **看板数据基准**：看板里的数是各站上报的月度汇总 + 半年度会议材料，不是实时数据，供运营参考。更新看板数据用主平台「📤 更新数据」上传解析。

## 技术约束

- 不引入任何外部 CDN，pptxgenjs / SheetJS 等组件库随项目同源部署（见 `libs/`）。
- 前端为纯静态文件，可直接用任意静态托管（GitHub Pages / 任意对象存储 / 内网服务器）；后端能力（论坛 / 看板 / 智子）按需接入 CloudBase，断网时前端自动降级为本地模式，功能可用。
